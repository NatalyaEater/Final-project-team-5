# Блок сортировки: #

Реализован принцип стратегии
путем создания общего интерфейса **SortStrategy** и трех сортировок.

> **Интерфейс SortStrategy**

Возвращает новую отсортированную коллекцию `MyArrayList<T>`.  
При этом исходная коллекция остаётся без изменений.  
Тип элементов < T >  совпадает с типом элементов исходной коллекции.

<u>**Главное преимущество:**</u>

Мы можем сортировать одни и те же исходные данные разными способами, не теряя их первоначальный порядок.  
`@param list` исходная коллекция.  
`@param comparator` компаратор, определяющий порядок элементов.



## Сортировки: ##

- BubbleSort

- InsertionSort


>**1. BubbleSort — пузырьковая сортировка объектов типа < T > .**

>>>Это простой алгоритм сортировки, основанный на последовательном сравнении соседних элементов массива и их обмене,
если они стоят в неверном порядке.

`BubbleSort<T>` может сортировать  `Animal`  по имени, возрасту, весу или всем трём полям.
Объекты других классов можно сортировать, передав подходящий `Comparator`.  
Сам алгоритм не знает, что такое имя, возраст или вес.
Он сравнивает элементы с помощью переданного компаратора.

**<u>Принцип работы BubbleSort :</u>**

Сравнить два соседних элемента.  
Если они расположены в неправильном порядке — поменять их местами.  
Перейти к следующей паре соседей.  
Повторять проходы, пока коллекция не будет отсортирована.

**<u>Назначение циклов:</u>**

Внешний цикл с переменной `i` управляет проходами.  
Внутренний цикл с переменной `j` сравнивает соседние элементы и при необходимости меняет их местами.  
После каждого полного прохода наибольший по компаратору
элемент неотсортированной части занимает своё место в её конце.  
Поэтому для коллекции из  `n` элементов достаточно максимум  `n - 1` проходов.

**<u>Досрочное завершение сортировки:</u>**

Для оптимизации используется переменная `swapped`,  
которая отслеживает, происходили ли перестановки
во время текущего прохода.

В начале каждого прохода `swapped = false`.  
Если два элемента меняются местами, устанавливается  `swapped = true`.  
Если за весь проход перестановок не произошло,
значит, коллекция уже отсортирована,
и внешний цикл завершается с помощью `break`.

Таким образом, алгоритм может завершиться раньше,
не выполняя все  `n - 1` проходов.




>**2. Insertion Sort — сортировка вставками.**

>>>Это алгоритм сортировки, который строит отсортированный массив по одному элементу за раз.   
Он берёт каждый новый элемент и «вставляет» его на правильное место среди уже упорядоченных элементов.  
Эффективно для конкретных сценариев, особенно когда данные уже частично упорядочены или массив небольшой.  
Алгоритм сохраняет относительный порядок равных элементов.  
Поскольку он сдвигает только элементы, которые строго больше текущего «ключа»,
равные элементы не меняются местами и сохраняют исходный порядок.

**<u>Принцип работы InsertionSort:</u>**

Первый элемент массива считается уже отсортированным.
Начиная со второго элемента, алгоритм выбирает текущий элемент `current`.  
Сравнивает его с элементами отсортированной части массива, двигаясь справа налево.  
Если элемент слева больше текущего, он сдвигается на одну позицию вправо.
Сдвиг продолжается, пока не найдётся подходящее место для текущего элемента.  
Текущий элемент вставляется на найденную позицию.
Действия повторяются, пока все элементы массива не будут отсортированы.

**<u>Назначение циклов:</u>**

Внешний цикл for с переменной `i` последовательно выбирает элементы массива, начиная со второго.  
Внутренний цикл while с переменной `j` сравнивает текущий элемент с предыдущими и сдвигает большие элементы вправо.  
После каждого прохода внешнего цикла отсортированная часть массива увеличивается на один элемент.  
Таким образом, для массива из `n` элементов внешний цикл выполняет `n - 1` проходов.


**<u>Завершение внутреннего цикла:</u>**

В сортировке вставками дополнительный `break` не требуется.  
Цикл `while` работает, пока выполняются два условия:
- `j >= 0` — индекс не вышел за левую границу массива.
- `comparator.compare((T) array[j], (T) current) > 0` — элемент слева больше текущего.

Как только хотя бы одно условие перестаёт выполняться, цикл `while` автоматически завершается.  
После этого текущий элемент вставляется на найденную позицию:
`array[j + 1] = current`.

В отличие от BubbleSort, здесь не используется переменная `swapped`,
поскольку внутренний цикл самостоятельно прекращает сдвиг элементов, когда нужная позиция найдена.

**<u>Использование временного массива:</u>**

Для сортировки создаётся временный массив `Object[] array`,
в который копируются элементы исходной коллекции `MyArrayList<T>`.  
Это необходимо, поскольку в нашей кастомной коллекции отсутствует метод **set()**,
позволяющий изменять элементы по индексу.  
После завершения сортировки элементы временного массива добавляются в новую коллекцию `MyArrayList<T>`,
которая возвращается методом **sort()**.  
Таким образом, исходная коллекция остаётся без изменений.
